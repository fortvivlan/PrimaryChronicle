## Повторная загрузка и проверка

Требуются Python 3 и `curl`. Вся коллекция занимает несколько гигабайт:
фотографии рукописи Андрея сохранены в исходном разрешении.

```bash
python3 scripts/download_sources.py
python3 scripts/download_sources.py --only daniel monomakh
python3 scripts/download_sources.py --verify
```

Повторный запуск проверяет уже сохранённые файлы и докачивает отсутствующие,
не заменяя оригиналы. Рядом с каждым файлом лежит `*.receipt.json`: исходный
и конечный URL, время загрузки UTC, размер и SHA-256. `--verify` работает
без сети. Успешная проверка подтверждает целостность загрузки, но не
текстологическую полноту памятника. Изображения сверяются с полными
перечнями [Пчелы](pchela-pages.json) и [Андрея](andrew-pages.json).

## Подготовка к лингвистическому анализу

Выделение оригинальных текстов, полный аудит и переносимый браузерный
редактор для эксперта описаны в [REVIEW.md](REVIEW.md).
Сборка: `python3 scripts/prepare_sources.py --zip`; результаты —
`data/old_russian/`, `data/expert_review/`, `data/expert_review.zip`.
Машиночитаемый аудит — [preparation-report.json](preparation-report.json).
В `texts/` находятся извлечённые HTML-оригиналы; смешанные OCR-страницы
и нерасшифрованные PUA-кодировки не выдаются за выделенный Unicode-корпус.

Для сканов подготовлен отдельный [процесс OCR/HTR](OCR.md):
план страниц, модели с контрольными суммами, возобновляемая обработка
и проверка результатов. Производные файлы находятся в `data/ocr/`;
они не являются вычитанными транскрипциями или ручной разметкой.

Это собрание исходных публикаций; тексты ещё не добавлены в таблицу демо.
HTML БЛДР содержит древнерусский текст рядом с современным переводом,
введением и примечаниями. Перед анализом их необходимо разделить.
Файлы `kirik/*-translation.html` — только современные переводы,
сохранённые как вспомогательный материал.

Летописи Изборника используют Windows-1251 и старую шрифтовую разметку:
например, `Ђ` может изображать ять. Транскрипции Манускрипта используют
частную область Unicode (PUA). Шрифты сохранены в `shryft/timeslit.ttf`
и `fonts/menaion.ttf`. Простое удаление HTML не даёт корректного
Unicode-текста; необходима проверяемая конверсия с сохранением оригинала.
Текстовый слой PDF Кирика также использует нестандартные шрифтовые коды.

Следует сохранять раздельно основной текст, варианты списков, исправления
издателей и автоматически распознанный текст. Для сканов нужны OCR/HTR
и вычитка; наличие OCR-слоя само по себе не подтверждает точности чтений.
Полное издание Жития Андрея А. М. Молдована (2000) и издание Флавия
по более раннему Архивскому хронографу (2002) остаются желательными
дополнениями; они пока не скачаны.

Описания Манускрипта разрешают свободное копирование транскрипций
«Пчелы» и «Чудес Николы» с обязательной ссылкой на ИРЯ РАН и
А. А. Пичхадзе. Описание сохранено в `support/manuscripts.html`.
Остальные публикации сохранены для локальной работы; решение о публикации
полных копий отдельно от данных демо ещё не принималось.
