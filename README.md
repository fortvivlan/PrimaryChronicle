# PrimaryChronicle

Одностраничная демонстрационная база лингвистических данных из «Повести
временных лет». Статический сайт находится в `docs/`: HTML, CSS, JavaScript
и JSON, без сборки и серверной базы данных.

Дальнейшая цель проекта — пополнять базу данными из других текстов. Для этого
нужно получить их цифровые версии и разработать автоматический разбор
с опорой на существующую ручную разметку «Повести временных лет».
Исходные цифровые тексты следует сохранять, а результаты автоматического
разбора — отличать от ручной разметки для последующей проверки и исправления.
Текущая демонстрация содержит данные «Повести временных лет»; добавление
новых текстов и их автоматический разбор — следующие этапы развития.

Фильтры: Лаврентьевская / Ипатьевская редакция / обе; одна или несколько
семантических меток; подлежащее `pro` или `NP`; протограф по стемме;
включительный диапазон лет с отдельным переключателем для преамбулы.
Счётчик показывает число найденных примеров из общего числа строк источника.

## Локальный просмотр

Из корня репозитория:

```bash
python3 -m http.server 8000 --directory docs
```

Открыть <http://localhost:8000>. Для загрузки JSON нужен HTTP-сервер;
открытие `index.html` через `file://` не поддерживается.

## Данные

Для расширения корпуса цифровые публикации и сканы собраны в `data/texts/`.
Состав коллекции, редакции, локальные пути и ограничения описаны в
[каталоге источников](sources/README.md). Сохранены обе версии ПВЛ,
летописные разделы и публикации памятников из рабочего списка; формат
варьируется от электронного текста до фотографий рукописи. Эти источники
пока не включены в демонстрационную таблицу. Повторная загрузка:
`python3 scripts/download_sources.py`; проверка локальных копий:
`python3 scripts/download_sources.py --verify`.

Сканы обрабатываются отдельно: [OCR/HTR и вычитка](sources/OCR.md).
`python3 scripts/ocr_sources.py --list` показывает задания;
результаты с постраничными координатами, оценками уверенности и контрольными
суммами сохраняются в `data/ocr/` со статусом `unreviewed`.

Подготовленные оригинальные тексты находятся в `data/old_russian/`;
смешанные OCR и нерасшифрованные шрифтовые коды выделены отдельно.
[Аудит и инструкция эксперту](sources/REVIEW.md) описывают ограничения.
Для вычитки **без Python и сервера** передайте `data/expert_review.zip`:
после распаковки открыть `expert_review/index.html` двойным щелчком.
Пакет включает редактор, сверку со сканами и экспорт правок; фотографии
Андрея и «Пчелы» по умолчанию подгружаются из Интернета.
Пересборка для сопровождающего: `python3 scripts/prepare_sources.py --zip`.

В крупнейшей таблице DOCX — 179 примеров (две строки заголовка не включены),
из них 8 в недатированной преамбуле. Датированные примеры: 852–1115 гг.
JSON находится в `docs/assets/records.json`; его можно публиковать вместе с сайтом.
Исходные DOCX/PDF в `data/` и локальный `AGENTS.md` игнорируются Git.

Чтобы повторить конвертацию (Python 3, без внешних библиотек):

```bash
python3 scripts/extract_data.py
# При нескольких DOCX укажите нужный файл явно:
python3 scripts/extract_data.py "data/ПВЛ ПЕРФ R 8.docx"
```

Скрипт выбирает крупнейшую таблицу, раскрывает вертикально объединённые ячейки,
переносит год в пустые ячейки продолжающихся примеров того же года,
сохраняет старославянские символы, `∅`, стрелки `→`, надстрочные примечания
и основное выделение текста. Основные чтения и варианты младших списков
сохранены раздельно. Идентификатор — порядковый номер строки данных;
`sourceRow` — номер строки исходной таблицы, считая с единицы.
`sourceYear` сохраняет исходный текст ячейки года, включая пустые ячейки.
В метаданных JSON сохранены имя и SHA-256 исходного DOCX.

Пустая семантическая ячейка не получает новой интерпретации: в описании
источника у Перфекта I нет отдельной семантической аннотации. Сомнительные
и смешанные подлежащие сохранены в исходном синтаксисе. Для двух явных
помет `pro ЛХП / NP И` и `pro Л / NP И` фильтр учитывает выбранную редакцию;
при выборе обеих редакций достаточно совпадения в одной из них.
Остальные типы подлежащего (QP, AP, wh) видны при выборе «Все».

Выбор редакции показывает её столбец и исключает строки без основного чтения
и вариантов в этой редакции; обе редакции не удваивают количество примеров.
Несколько семантических меток объединяются через «или», разные фильтры —
через «и». Протограф выбирается как полное чтение, включая сочетания с `~`,
`/` и `→`; унифицируются только пробелы и кириллическое `а` в `Iа`.
Исходное написание всегда остаётся в таблице.

## GitHub Pages

После коммита и отправки файлов в GitHub, в **Settings → Pages** выбрать
**Deploy from a branch**, ветку **main** и папку **/docs**, затем **Save**.
Сайт подготовлен для адреса `https://fortvivlan.github.io/PrimaryChronicle/`;
все пути к ресурсам относительные. Эти настройки соответствуют
[инструкции GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).
